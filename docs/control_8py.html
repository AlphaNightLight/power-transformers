Computes covariance matrices from standard deviations.

Parameters
theta_o_stdfloat, standard deviation of top-oil temperature
theta_h_stdfloat, standard deviation of hotspot temperature
measurement_stdfloat, standard deviation of the measurements
pIECparams, parameter object
Returns
Q: np.ndarray[3,3], prediction covariance matrix
R: np.ndarray[1,1], measurement covariance matrix

This functions converts the standard deviation of the outputs into the prediction covariance matrix Q, assuming independence between the variables and then producing a diagonal matrix. Similarly, the standard deviation of the measurement is used to generate the measurement covariance matrix R under the same assumption.
