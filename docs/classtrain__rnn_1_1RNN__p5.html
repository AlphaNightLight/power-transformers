Detailed Description

RNN subclass with 4 parameters in A_prime, 1 parameter in B_prime and MSE loss.

Subclass of RNN_base, with the following specifications:

\[ A' = \begin{matrix} a & b & 0 \\ 0 & 0 & 0 \\ 0 & c & d \end{matrix} \qquad\qquad\qquad B\ ' = \begin{matrix} e & 0 & 0 \\ 0 & 0 & 0 \\ 0 & 0 & 0 \end{matrix} \qquad\qquad\qquad Loss = MSE \]
